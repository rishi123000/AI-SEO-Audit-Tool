AI SEO Audit Tool

An AI-powered SEO audit application that uses Google Apps Script and the Gemini API to generate an AI-assisted SEO report from a website URL.

 Project Overview
 
The AI SEO Audit Tool allows users to enter a website URL and receive an AI-generated preliminary SEO assessment.

The tool generates recommendations covering:

- SEO Score
- Meta Title
- Meta Description
- Heading Structure
- Keyword Suggestions
- Technical SEO
- Image Alt Text
- Internal Linking
- Top SEO Recommendations

Technologies Used

- Google Apps Script
- HTML
- CSS
- JavaScript
- Gemini API
- Google Apps Script Web Apps

 How It Works

User enters a website URL

↓

Frontend sends the URL to Google Apps Script

↓

Google Apps Script communicates with Gemini API

↓

Gemini generates an SEO assessment

↓

The SEO report is displayed in the web application

 Key Features

- Simple website URL input
- AI-powered SEO recommendations
- Automated SEO report generation
- SEO score generation
- Technical SEO recommendations
- Keyword suggestions
